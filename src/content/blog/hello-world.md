## 为什么选静态站

静态站把「写文章」和「展示」彻底分开：文章是仓库里的 Markdown 文件，页面是构建时生成的 HTML。没有服务器要维护，也没有数据库要备份。

好处很直接：

- 打开速度快，页面就是纯 HTML
- 不用管服务器、证书、续费
- 文章全部在 Git 里，随时可以回滚

> 代价是没有网页后台，写文章要在本地编辑再提交。

## 目录结构

```text
src/
├── content/blog/     # 文章，一个 .md 一个页面
├── layouts/          # 页面骨架
├── pages/            # 路由
└── styles/           # 全局样式
```

## 怎么写新文章

在 `src/content/blog/` 下新建一个 `.md` 文件，开头写 frontmatter：

```markdown
---
title: 文章标题
description: 一句话摘要，会显示在列表页
pubDate: 2026-11-12
tags: ['标签']
---
```

正文从下一行开始写就行。保存后本地开发服务器会自动刷新，提交后自动重新部署。
